# Practica propuesta #12

Desarrollar un programa en Python que, dada la siguiente lista:

```python
numeros = [1, 2, 3, 4, 5]
```

Elimine el primer y último elemento de la lista, tomando en cuenta que desconocemos los elementos que componen a nuestra lista.

Posteriormente, el programa deberá mostrar por pantalla dos listas.
 \>> La primera lista será la que contiene los elementos que no fueron eliminados
 \>> La segunda lista deberá contener los elementos que fueron eliminados.

Salida esperada:

```python
# Lista números: [1, 2, 3, 4, 5]
# Lista números: [2, 3, 4]
# Lista números eliminados: [1, 5]
```
