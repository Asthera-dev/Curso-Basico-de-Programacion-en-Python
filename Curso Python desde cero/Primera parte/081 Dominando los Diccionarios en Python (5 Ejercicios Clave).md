# 5 ejercicios clave para dominar los diccionarios.

A continuación se presenta un total de 5 ejercicios para que el lector pueda empezar a dominar el uso de diccionarios dentro del lenguaje de programación Python.
## Ejercicio #1

Desarrollar un programa que contenga un diccionario con la siguiente estructura:

```python
frutas = {"manzanas": 5,
		  "peras": 2,
		  "naranjas": 4
		  }
```

Este primer programa deberá devolver el número de manzanas que hay dentro del diccionario. 

```python
# Salida esperada:

# Ejercicio #1:
# {'manzanas': 5, 'peras': 2, 'naranjas': 4}
# Cantidad de manzanas: 5
```

## Ejercicio #2

Desarrollar un programa que contenga un diccionario con la siguiente estructura: 

```python
frutas = {"manzanas": 5,
		  "peras": 2,
		  "naranjas": 4
		  }
```

El programa deberá agregar tres nuevos ítems al diccionario con las siguientes especificaciones :

	"bananas": 5,    "mangos": 6,    "uvas": 3

```python
# Salida esperada:

# Ejercicio #2
# Diccionario original: {'manzanas': 5, 'peras': 2, 'naranjas': 4}
# Diccionario modificado: {'manzanas': 5, 'peras': 2, 'naranjas': 4, 'bananas': 5, 'mangos': 6, 'uvas': 3}
```

## Ejercicio #3

Desarrollar un programa que contenga un diccionario con la siguiente estructura: 

```python
frutas = {"manzanas": 5,
		  "peras": 2,
		  "naranjas": 4
		  }
```

El programa deberá eliminar el par **clave-valor** correspondiente a la clave "peras".

```python
# Salida esperada:

# Ejercicio #3
# Diccionario original: {'manzanas': 5, 'peras': 2, 'naranjas': 4}
# Diccionario modificado: {'manzanas': 5, 'naranjas': 4}
```

## Ejercicio #4

Desarrollar un programa que contenga un diccionario con la siguiente estructura: 

```python
frutas = {"manzanas": 5,
		  "peras": 2,
		  "naranjas": 4
		  }
```

El programa deberá retornar dos listas, la primera lista debe contener todas las claves del diccionario y la segunda lista deberá contener todos los valores del diccionario.

```python
# Salida esperada:

# Ejercicio #4
# Diccionario original: {'manzanas': 5, 'peras': 2, 'naranjas': 4}

# Lista de claves: ['manzanas', 'peras', 'naranjas']
# Lista de valores: [5, 2, 4]
```

## Ejercicio #5

Desarrollar un programa que contenga un diccionario con la siguiente estructura: 

```python
frutas_01 = {"manzanas": 5,
		  "peras": 2,
		  "naranjas": 4
		  }

frutas_02 = {"uvas": 5,
		  "peras": 2,
		  "naranjas": 4
		  }
```

El programa deberá retornar **'True'** si la clave "manzanas" existe en el diccionario y 'False' si la clave no existe.

```python
# Salida esperada:

# Ejercicio #5

# Diccionario original: {'manzanas': 5, 'peras': 2, 'naranjas': 4}
# ¿La clave manzanas existe en el diccionario?
# True

# Diccionario original: {'uvas': 5, 'peras': 2, 'naranjas': 4}
# ¿La clave manzanas existe en el diccionario?
# False
```
