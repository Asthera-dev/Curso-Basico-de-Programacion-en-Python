# Recorriendo una tupla

Esta nota será corta y solo tendrá un ejemplo de como se puede recorrer uno a uno los elementos de la tupla.

```python
tupla = ("a", "e", "i", "o", "u")

for vocal in tupla:
	print(vocal)

# Salida:

# a
# e
# i
# o
# u
```

Como se observa, el comportamiento del ciclo for dentro de la tupla es muy similar al comportamiento del mismo bucle con una lista.
