# Proyecto #4 - Conversor de entero a romano

Crea un programa que permita convertir un número entero a su equivalente en números romanos, con las siguientes especificaciones:

* El programa deberá solicitar al usuario que ingrese un número entero.
* El programa solo aceptara números enteros en un rango entre 1 y 3999.

Ejemplos de salida:

```python
# >> Ingrese un numero entero entre 1 y 3999: 200

# >>> El numero 200 en numeros romanos es:
# CC
```

```python
# >> Ingrese un numero entero entre 1 y 3999: 12

# El numero 12 en numeros romanos es:
# XII
```

```python
# >> Ingrese un numero entero entre 1 y 3999: 500

# >>> El numero 500 en numeros romanos es:
# D
```

```python
# >> Ingrese un numero entero entre 1 y 3999: 0
# 
# ¡Error! El numero debe estar entre 1 y 3999.
#
# >> Ingrese un numero entero entre 1 y 3999: 4000
#
# ¡Error! El numero debe estar entre 1 y 3999.
# 
# >> Ingrese un numero entero entre 1 y 3999: 3999
# 
# >>> El numero 3999 en numeros romanos es:
# MMMCMXCIX
```
