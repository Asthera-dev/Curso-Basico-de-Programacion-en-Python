# Practica propuesta #13

Desarrollar un programa que genere una matriz con valores de tipo entero desde teclado de manera automatizada con las siguientes características:

\>> **En Primer lugar:** El usuario tendrá que especificar, a través de teclado, la cantidad de filas y columnas que tendrá la matriz que desea generar.

\>> **En Segundo lugar:** El programa deberá pedir al usuario todos los valores que contendrá la matriz, elemento a elemento.

\>> En **Tercer lugar**: Cuando el programa termine su ejecución, se deberá mostrar en pantalla la matriz resultante en formato de matriz.

Ejemplo:

```python
# >> ¿Cuantas filas tendra la matriz?: 3
# >> ¿Cuantas columnas tendrá la matriz?: 3

# >> Introduce un elemento a la fila 0, columna 0: 1
# >> Introduce un elemento a la fila 0, columna 1: 2
# >> Introduce un elemento a la fila 0, columna 2: 3

# >> Introduce un elemento a la fila 1, columna 0: 4
# >> Introduce un elemento a la fila 1, columna 1: 5
# >> Introduce un elemento a la fila 1, columna 2: 6

# >> Introduce un elemento a la fila 2, columna 0: 7
# >> Introduce un elemento a la fila 2, columna 1: 8
# >> Introduce un elemento a la fila 2, columna 2: 9

# Salida Esperada:

# [1, 2, 3]
# [4, 5, 6]
# [7, 8, 9]

```
