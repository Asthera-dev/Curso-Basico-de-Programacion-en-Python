# Ejercicio práctico #15

Desarrollar un programa que permita recibir un String a través de teclado, en seguida se deberá crear un diccionario que almacene la cantidad de veces que aparece cada una de las letras o caracteres que componen al String.

Ejemplo de salida esperada:

```python
# >> Ingrese un texto: mi mama me mima

# {'m': 6, 'i': 2, ' ': 3, 'a': 3, 'e': 1}
```

Como se observa, este programa nos retorna la cantidad de ocurrencias de cada carácter presente en la frase, incluido los espacios en blanco.
