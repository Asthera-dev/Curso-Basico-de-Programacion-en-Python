# Práctica propuesta #8

Desarrollar un programa que muestre en pantalla la tabla de multiplicar de un número cualquiera. Este número deberá ser solicitado e ingresado desde teclado por el usuario.

## Requerimientos indispensables:

* Utilizar el ciclo o bucle for
* La tabla debe contener las multiplicaciones que van desde el 0 hasta el 10.

Ejemplo de salida esperada:

```python
# Tabla ingresada por el usuario: 5

# Ejemplo de salida esperadada:
"""
La tabla del 5 es:
5 X 0 = 0
5 X 1 = 5
5 X 2 = 10
5 X 3 = 15
5 X 4 = 20
5 X 5 = 25
5 X 6 = 30
5 X 7 = 35
5 X 8 = 40
5 X 9 = 45
5 X 10 = 50
"""
```

> 
> La respuesta a este ejercicio se tratara en la clase presencial.
