Las palabras reservadas, son **identificadores** para uso exclusivo del lenguaje de programación, que no pueden ser utilizadas para identificar y nombrar variables, métodos, objetos o cualquier elemento dentro de nuestro código.

Al intentar utilizar alguna de estas palabras reservadas fuera del uso que tienen asignado, lo que obtendremos será un error de compilación y nuestro programa no podrá ser ejecutado.

En Python, existen un total de 28 palabras reservadas, las cuales fueron asignadas para uso exclusivo del lenguaje de programación.

Estas palabras son las siguientes:

* and
* del
* for
* is
* raise
* assert
* if
* else
* elif
* from
* lambda
* return
* break
* global
* not
* try
* class
* except
* or
* while
* continue
* exec
* import
* yield
* def
* finally
* in
* print

**Están escritas en minúsculas y no podrán ser usadas para nombrar variables u otros elementos dentro de nuestro código**.
