En programación, un tipo de dato es un atributo de los datos que indica a la computadora y al programador, sobre la clase de datos que se va a manejar.

En Python, existen los siguientes tipos de datos (los principales):

1. Enteros y Largos
2. Flotantes
3. Números complejos
4. Cadenas
5. Booleanos

## Enteros y Largos

Son aquellos que no tienen decimales, tanto positivos como negativos.

En Python se pueden representar mediante el tipo ***int*** (entero) o el tipo ***long*** (largo).

# Flotantes o Reales

Son los que tienen decimales, tanto positivos como negativos.

En Python se expresan mediante el tipo ***float***.

## Números complejos

Son aquellos que tienen una parte real y una parte imaginaria.

La mayor parte de lenguajes de programación carecen de este tipo, aunque sea muy utilizado por ingenieros y científicos en general.

En Python se expresan mediante el tipo ***complex***.

## Cadenas (o Strings)

No son más que texto entre comillas simpes ('cadena') o dobles ("cadena").

También es posible encerrar una cadena entre triples comillas (simples o dobles).

De esta forma podremos escribir el texto en varias línea y al imprimir la cadena, se representarán los saltos de línea que introdujimos sin tener que recurrir al carácter ***\n***.

## Booleanos

Sólo puede tener dos valores: ***True*** (cierto) y ***False*** (falso). Estos valores son especialmente importantes para las expresiones condicionales y los bucles, mismos que ya estudiaremos posteriormente.

En Python se expresan mediante el tipo ***bool***.
