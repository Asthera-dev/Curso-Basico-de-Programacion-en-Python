# Curso-Basico-de-Programacion-en-Python

> El “Curso Básico de Programación en Python” es una iniciativa académica organizada por el capítulo Computer Society de la Rama Estudiantil IEEE de la Universidad Autónoma Chapingo. Este curso tiene como objetivo desarrollar habilidades de programación estructurada en los estudiantes de primeros semestres.

> Es importante mencionar que las notas del curso corresponde una transcripción directa (y en ocasiones adaptada y reinterpretada) del curso "Curso de programación Python desde cero" pertenecientes al creador de contenido "La Geekipedia De Ernesto".
